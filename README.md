# 🛠 Amazon Sales ETL Pipeline (Databricks + PySpark)

An end-to-end ETL pipeline built with PySpark on Databricks, processing fictional Amazon sales data for the year 2025. The project includes data cleaning, transformation, ranking, and insights generation.

## 🚀 Features
- Ingest CSV and convert to Delta Lake format
- Clean & transform data using PySpark
- Use window functions to rank top-selling products
- Create customer-level and category-level insights
- Export data to dashboards or downstream apps
- Designed to be production-ready and schedulable

## 🧰 Tech Stack
- Databricks (Notebooks, Delta Lake, Workflows)
- PySpark
- SQL (Window Functions, Aggregations)
- VS Code + Jupyter
- Git & GitHub
